# Project Statement

## 1. Problem Statement

Educational institutions need to maintain basic academic information about students in an organized manner.

The objective of this project is to develop a Java-based Student Academic Management System using Object-Oriented Programming concepts.

The system represents people, students, and graduate students using classes and demonstrates encapsulation, inheritance, abstraction, interfaces, and runtime polymorphism.

The application also performs validation for student names, email addresses, GPA, and research grants.

## 2. Scope of the Project

The scope of this project includes:

- Creating Student and GraduateStudent objects.
- Maintaining person identification details.
- Storing student names and email addresses.
- Storing and validating GPA.
- Representing graduate students as specialized students.
- Storing research grant information.
- Calculating tuition fees.
- Applying research grant deductions.
- Displaying student records.
- Demonstrating Object-Oriented Programming concepts.
- Demonstrating runtime polymorphism and method overriding.

The project is designed as an educational Java console-based application.

## 3. Target Users

The target users of this project are:

- Java programming students
- OOP learners
- College and university students
- Teachers and instructors
- Students preparing Java assignments
- Beginners learning inheritance and polymorphism

## 4. High-Level Features

### Student Management

The system stores:

- Person ID
- Name
- Email
- GPA

### Graduate Student Management

Graduate students additionally store:

- Research Grant

### Data Validation

The system validates:

- Name should not be null or empty.
- Email should contain @.
- GPA should be between 0.0 and 4.0.
- Research grant should not be negative.
